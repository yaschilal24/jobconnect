# User Guide

## Seeker
1. Register → Job Seeker
2. Complete profile (education, experience, skills, resume)
3. Browse jobs → Apply → track status
4. Save jobs, receive notifications

## Company
1. Register → Company
2. Create company profile
3. Post jobs → track applicants → shortlist/interview/hire
4. View interviews

## Admin
1. Login
2. View stats, users, companies, jobs, audit logs, reports
3. Verify companies, toggle users, delete jobs
